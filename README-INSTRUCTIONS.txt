AUTOSHEET CATALOGUE UPDATE — IMPORTANT

Files in this ZIP:
- index.html: replacement homepage that clearly explains the store is being prepared.
- catalogue.html: proposed product ideas and indicative INR price ranges.

These are ideas only, not actual completed products. They are explicitly marked as proposed and unavailable. No checkout, Razorpay integration, or automated email delivery is included or claimed.

HOW TO UPDATE GITHUB PAGES
1. Download and extract this ZIP.
2. Open https://github.com/tiktom666-cloud/autosheet-store
3. Click Add file > Upload files.
4. Upload index.html and catalogue.html from this folder to the repository ROOT.
5. If GitHub asks whether to replace index.html, choose the option to replace/update it.
6. Commit changes to the main branch.
7. Wait a few minutes, then open https://tiktom666-cloud.github.io/autosheet-store/ and refresh.
8. Test the Product ideas & pricing link.

IMPORTANT
- Do not upload paid product files, customer information, Apps Script secrets, or Razorpay secret keys to the public repository.
- Before opening sales, build and test each real template, replace proposed ideas with actual products, verify compatibility, and implement server-side payment verification and secure email delivery.
- Suggested price ranges are planning estimates, not verified market research.
