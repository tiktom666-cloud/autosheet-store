# AutoSheet public website (GitHub Pages)

This folder contains the public marketing storefront and policy-page drafts. It is intentionally a static website and **does not process payments by itself**.

## Publish using GitHub Pages
1. Create a public GitHub repository named `autosheet-store`.
2. Upload all files in this `website` folder to the repository root (not the `website` subfolder).
3. In repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Wait for GitHub Pages to publish the site. Your URL will look like `https://YOUR-USERNAME.github.io/autosheet-store/`.

## Before submitting to Razorpay
- Replace all placeholder business/contact details.
- Replace sample product listings and sample prices with actual products.
- Publish accurate policies that match your real practices.
- Confirm that your products are actually available and delivery works.
- Use the actual website URL generated by GitHub Pages in the Razorpay Website/App field.
- Razorpay may still require additional evidence or reject a site that does not meet its current review requirements.

## Important current limitations
- Product cards are sample content.
- Checkout buttons are intentionally not enabled.
- No customer login, purchase dashboard or protected downloads are included in this static preview.
- Do not accept real payments until the Apps Script backend, Razorpay integration, email delivery and customer purchase dashboard are separately implemented and tested.
